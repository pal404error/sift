Section B · The Pipeline

How It Works

Three stages between your sources and a grounded answer.

1

Ingest & Crawl

The orchestrator concurrently pulls pages from your sources, respecting robots.txt and gracefully handling incremental re-crawls via ETags.

2

Embed & Store

Content is intelligently chunked, passed through your chosen embedding provider, and indexed into your active vector store.

3

Retrieve & Generate

Queries are vectorized, optionally reranked with cross-encoders, and answered by your preferred LLM with transparent sources attached.

Section C · Wire Dispatch

Up And Running In Seconds

Sift ships with mock providers natively, letting you test the full RAG pipeline offline with zero API keys.

Terminalbash
# Clone the repository
git clone https://github.com/pal404error/sift.git
cd sift

# Install locally
pip install -e .

# Start the server (fakes enabled by default for zero-config testing)
sift serve

# Or deploy using Docker Compose
docker compose up -d
Section D · Q & A

Frequently Asked Questions

Common questions about architecture, hosting, and features.

Is Sift Fully Open Source?
Yes, Sift is completely open source and released under the permissive MIT license. You can fork it, modify it, and use it freely for both personal and commercial enterprise projects.
Which AI Models Does Sift Support?
Sift features a highly pluggable architecture. Out of the box, we provide first-class support for OpenAI, Anthropic, and Ollama (for local inference). We also include mock fake providers that let you test the entire pipeline without requiring API keys or internet access.
How Does The Crawl Orchestrator Work?
The built-in concurrent crawler orchestrator is designed for production efficiency. It strictly obeys robots.txt, supports ETags for bandwidth-saving incremental crawls, and handles chunking securely before passing data to the embedding pipeline.
Can I Integrate This With My Existing Identity Provider?
Absolutely. Sift includes enterprise-ready OIDC and JWKS authentication, alongside API-key based Role Based Access Control (RBAC). It's built to drop straight into corporate environments securely.
How Do I Monitor Sift In Production?
Sift comes instrumented with /metrics and /health endpoints natively. It seamlessly integrates with Prometheus and Grafana for comprehensive observability, and maintains a robust audit log for security tracing.
